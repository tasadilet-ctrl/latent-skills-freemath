=== 1. DUMMY  vs  EMPTY  (what you subtract when extracting) ===============

                8B          27B
  vs DUMMY    25.82       35.20      = skill only
  vs EMPTY    27.14       39.31      = skill + "a system prompt exists"
              -----       -----
  EMPTY wins  +1.32       +4.11

  EMPTY wins on accuracy, on both models.
  BUT empty is the dirty one: it never removes the generic
  "there is a system prompt telling me to be careful" signal.

  FULL CONTROL SET (27B, L62 gamma 0.3, all vs baseline 33.06):

      skill @ system                       +6.25   p=0.003
      placebo-only @ system   NO SKILL     +3.62   p=0.073
      skill @ user                         +2.47   p=0.232
      placebo-only @ user     NO SKILL     +4.11   p=0.041
      skill @ system, placebo subtracted   +2.14   p=0.302

  READ THIS CAREFULLY. At user position the CONTENT-FREE placebo vector
  (+4.11) BEATS the actual skill vector (+2.47). Every vector built as
  (some instructional text) - (nothing) gives roughly +2 to +6, and which
  text you use does NOT track whether it is a relevant skill.

  The only arm that isolates skill content -- skill minus a matched placebo
  at the same position -- gives +2.14, not significant.

  => There is NO EVIDENCE on this benchmark that the skill CONTENT contributes
     anything beyond generic text-derived steering.
  => p=0.041 does not survive correction over the ~10 comparisons run
     (Bonferroni threshold ~0.005).

  An earlier reading of this data claimed a clean additive split
  (3.62 + 2.14 ~= 6.25, "58% confound / 34% procedure"). That decomposition
  does NOT hold at user position and should not be reported.

  => Do NOT write this up as "latent skills beat text skills".
  => The defensible claim is about the CONTROL, not the effect: steering with
     a text-derived direction helps, and a content-free control direction
     helps as much. Report that.

  Opposite verdict from fidelity (how well the vector copies the text skill):
      8B  vs DUMMY  +0.430   <- much better copy
      8B  vs EMPTY  +0.236
  So the dummy gives the PURER vector and the WORSE score.
  Fidelity and accuracy disagree; report them separately.

  DECISION: USE THE DUMMY, and ALWAYS publish the placebo-only control row
  next to it. Empty's advantage is a measured artifact (+3.62 at system,
  +4.11 at user, both from vectors containing no skill). Moving the skill to
  the user turn does NOT avoid this -- it was tried and the control got
  bigger, not smaller.

=== TWO HARNESS BUGS THAT WOULD HAVE INVERTED THE CONCLUSIONS ==============

  1. 27B truncation. At 2048 tokens, 51.6% of 27B replies hit the cap
     mid-sentence and never reached "Answer:". The cell scored 16.94% --
     BELOW the 20% chance floor -- making the big model look worse than
     the small one. Fixed with 4096 tokens + answer-forcing: 33.06%.
     A 16-point correction.

  2. Filename collision. Artefacts carried no model tag, so an 8B run and
     a 27B run wrote the same path and the second destroyed the first --
     across exactly the two models being compared. Fixed.
