# Screen for Relevance, Audit the Scope, Then Rank

1. **Name the exact question.** Write one line fixing what is asked — which
   object, which property, which limit — and the hypotheses granted. Every
   candidate is judged against that line and nothing else.

2. **Discard candidates that answer a different question.** A candidate about
   another object, another limit, another mode of convergence, or a conclusion
   the setup never raises is wrong however true it sounds. Do this first; it is
   the cheapest elimination available and it removes the most candidates.

3. **Audit the scope of each survivor.** For each, name what it quantifies
   over, in what sense (pointwise or uniform, a fixed region or a shrinking
   one, which norm), and over what range of the parameter it is claimed to
   hold. Two candidates often differ only here.

4. **Reject over-claims as firmly as under-claims.** A candidate needing more
   than the hypotheses grant — an upgraded convergence, a fixed-scale bound
   where only a truncated one is available, a uniformity nothing supplies — is
   false, not strong. Strength is never evidence of correctness.

5. **Rank by strength only what survived steps 2-4.** Among candidates all
   compatible with the hypotheses, prefer the strongest: one implied by another
   is the standard wrong answer. Never rank before eliminating.

6. **Separate the last two by a case.** If two survive, name the configuration
   where they disagree and decide which the hypotheses support there. Do not
   settle it on which sounds more substantial.

7. **Give the letter alone** on the final line, with no restatement of the
   reasoning.
