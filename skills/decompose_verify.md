# Decompose, Solve Stepwise, Verify

1. **Restate the goal.** Before computing anything, write one line naming the
   single quantity the question asks for. Do not begin until that line exists.

2. **Extract the knowns.** List every given value with its unit and what it
   refers to. Mark values that are stated *relative* to another value
   ("twice as many", "3 fewer than") — these must be resolved before use.

3. **Decompose into sub-results.** Break the problem into the smallest
   sub-quantities that can each be computed from knowns already on the list.
   Order them so every sub-result depends only on earlier ones.

4. **Solve one step at a time.** Compute one sub-result per line, showing the
   arithmetic. Never combine two steps into a single expression.

5. **Verify before answering.** Check each sub-result against the constraints in
   the problem: do the units match, is the magnitude plausible, does substituting
   the answer back reproduce the given totals?

6. **Backtrack on contradiction.** If verification fails, do not patch the final
   number. Return to the earliest step whose assumption the contradiction
   implicates, correct it there, and recompute forward from that point.

7. **State the answer alone** on the final line, with no restatement of the work.
