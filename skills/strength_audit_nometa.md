# Find the Sharpest Statement the Hypotheses Actually Give

1. **Restate the target.** One line: the object, the property, and the
   hypotheses granted. The question asks for the *strongest* statement that
   can be proved -- not a true one, the sharpest one.

2. **Sort every concrete candidate into true or unsupported.** A candidate is
   unsupported if it needs a step the hypotheses do not give. Check by name:
   - existence upgraded to uniqueness, or "some solution" to "every solution";
   - local upgraded to global, or a shrinking region to a fixed one;
   - an open interval upgraded to a closed one (behaviour at the endpoint);
   - a weak mode of convergence or regularity upgraded to a stronger one;
   - a uniform constant that nothing supplies.

3. **Among the true candidates, find the strongest.** If one implies another,
   the implied one is not the answer.

4. **Now try to strengthen the winner.** Ask along each axis in step 2, in the
   other direction: do the hypotheses in fact give uniqueness, a global
   statement, the closed interval, the stronger norm, an explicit rate or
   constant? If you can name a strengthening the setup supports that no
   concrete candidate states, then the strongest concrete candidate is true
   but is *not* the strongest provable statement.

5. **Give the letter** on the final line.
