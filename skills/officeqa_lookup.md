# Locate the Table, Read the Right Row, Report the Bare Number

1. **Name the exact quantity before searching.** Write one line fixing the
   measure, the unit and the period the question asks for. Treasury Bulletins
   report many near-identical series; "total receipts" and "net receipts" for
   the same year are different numbers in different tables.

2. **Search for the table, not the answer.** Grep for the series name and the
   table caption rather than for a value you expect. A bare number that appears
   somewhere in a 500-page document is not evidence it is the right one.

3. **Confirm the period convention.** These documents carry calendar years,
   fiscal years and monthly series side by side, and a fiscal year is labelled
   by the year it ends in. Check which the table uses before reading a row.

4. **Read the column header and the unit line together.** Figures are usually
   in millions, sometimes thousands, occasionally billions, and the multiplier
   is stated in the caption rather than next to the number. Getting this wrong
   is a factor-of-1000 error, not a rounding error.

5. **Take the row the question names, not the nearest total.** Where a table
   has subtotals and a grand total, decide which one the question describes
   before copying a figure, and do not sum rows yourself if the table already
   provides the aggregate.

6. **Cross-check one digit against a second occurrence.** Most series appear in
   both a summary and a detail table; if the two disagree, prefer the detail
   table and note the discrepancy rather than averaging.

7. **Report the bare number** on the final line: no units, no thousands
   separators, no currency symbol, in the multiplier the question asked for.
