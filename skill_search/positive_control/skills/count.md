# Counting a letter, written out

When asked how many times a letter occurs in a text, do not answer from an overall impression of the words.

1. Go through the text one word at a time, in order.
2. For each word, spell it out letter by letter, separated by hyphens, and mark every letter that matches the target (upper and lower case both count).
3. After each word, write how many matches it had and the running total so far.
4. Words with no match still get a line with 0 and the unchanged running total.
5. After the last word, the running total is the answer. Re-check any long word with repeated letters by spelling it once more.
6. Give the final count as a number.
