# Route first

Your reply has a limited length; do not spend it on brute force.

1. Before computing, name two or three possible routes and take the one with the least computation.
2. Use structure (closed form, symmetry, invariant, periodicity, solving for a threshold directly) instead of tabulating terms or trying values one by one.
3. If a route stalls, switch to the next one rather than grinding.
4. Check the result once on a small or limiting case. Use answer options to check only if options are listed.
5. Always end with the answer line in the form the question asks.
