THE HEADLINE
--------------------------------------------------------------------------------
Two complete 4-condition matrices, on different benchmarks, different models and
different harnesses, show the SAME structure:

                              LiveMath 27B      SpreadsheetBench 14B
                                                (single-turn)
  baseline                       33.06                20.10
  text skill                     34.70  (+1.64)       22.61  (+2.51)
  embed vs NOTHING               39.31  (+6.25)*      22.36  (+2.26)
  embed vs DUMMY                 35.20  (+2.14)       20.35  (+0.25)
                                                      * p=0.003

  The UNCONTROLLED vector carries most or all of the text skill's effect.
  Subtracting a matched placebo removes it.

  => What activation steering contributes on these tasks tracks the PRESENCE of
     instructional text in the extraction contrast, not the PROCEDURAL CONTENT
     of the skill.

  5 of 6 positive (+1.6 to +4.0); under the null you would expect ~3. No single

  so a pooled test is the honest way to ask whether the effect is real.

--------------------------------------------------------------------------------
FIDELITY DOES NOT PREDICT EFFECT
--------------------------------------------------------------------------------
  fidelity = 1 - KL(text||steered)/KL(text||plain)   -- the method's own
  validation metric, i.e. how well the vector reproduces the text skill.

  LiveMath vs-dummy:   8B +0.430   14B +0.638   27B +0.229

  The 14B vector reproduces the text skill BEST in the whole study (+0.638)
  and gives -0.16 accuracy, while the TEXT form gives +2.30.
  The 14B's WORST vector (+0.192) gives +0.82.

  => Distributional fidelity to a text skill does not imply behavioural
     equivalence. This is a direct problem for the standard validation
     approach in the activation-steering literature.

  floor KL(text||plain), i.e. how much the skill moves the model at all:
     LiveMath 0.82-0.89     SpreadsheetBench 0.19-0.22
  The same skill text perturbs the model ~4x less in a long agentic context.

HARNESS EQUIVALENCE (validates a substitution)
--------------------------------------------------------------------------------

     agent harness (20 turns, terminal)   baseline 20.00   text +4.00
     single-turn code generation          baseline 20.10   text +2.51

  Near-identical baselines and same-direction skill effects. Giving this model
  a terminal and 20 turns buys nothing over one shot at writing the script.

--------------------------------------------------------------------------------
CAVEATS TO CARRY INTO THE WRITE-UP
--------------------------------------------------------------------------------
 1. The LiveMath skill (compare_claims_v3) was revised after inspecting the
    AGGREGATE distractor-role histogram of v1/v2 on the same 608 items. Only the
    marginal distribution was used, never per-item labels. Declare it.
 2. The placebo-only CONTROL cells are +3.62 (p=0.073) and +4.11 (p=0.041);
    neither survives correction. They AGREE across two prompt positions, which
    is worth something, but neither is individually significant.
 3. One run per cell, greedy decoding. Deterministic, so no run-to-run variance
    estimate; all uncertainty is sampling error over items.
 4. SpreadsheetBench uses the verified-400 subset, which scores ONE test case
    per task where the full benchmark requires all of them. Not comparable to
    the ~50% published SOTA.
 5. OfficeQA excludes 7 of 246 questions whose source bulletins failed their
    manifest sha256 (upstream changed them).
 6. The embed arm for the AGENT harnesses was not run: steering needs the
    residual stream, vLLM cannot provide it, and the hooked HF server is ~500x
    slower per token. OfficeQA has no single-turn fallback because its
    documents do not fit in context.
